4) KANAN: panel 'Gemini Agent' PERMANEN, tidak tertutup, tidak diganti Inspector. Header contoh 'Gemini • Siap • 24/100 key'; tombol 'Kelola API'; baris konteks 'Konteks: Layer Artwork'; area aktivitas ringkas dan input 'Minta Gemini mengedit proyek…'. Jangan tampilkan kredensial asli.

KONTEN WAJIB PANEL INSPECTOR KIRI (FOKUS GAMBAR)
- Judul panel: 'Inspector' dengan badge 'Artwork'; subjudul 'Layer: Artwork'.
- Kelompok 'Animasi Masuk': dropdown preset bernilai 'Zoom In', kontrol 'Durasi 0,8 dtk', easing 'Ease Out'.
- Kelompok 'Animasi Keluar': dropdown preset bernilai 'Fade Out', 'Durasi 0,6 dtk'.
- Kelompok 'Animasi Loop': dropdown preset bernilai 'Slow Zoom', toggle 'Aktif' (menyala), intensitas 'Halus'.
- Kelompok 'Keyframe Manual': property picker sederhana bernilai 'Opasitas', ruler MINI hanya di dalam Inspector (bukan lane timeline utama) dengan dua tanda keyframe berlian pada detik 0,0 dan 2,5; field 'Waktu 2,5 dtk', 'Nilai 85%', tombol 'Tambah Keyframe' dan 'Hapus Keyframe'.
- Petunjuk kecil: 'Posisi, skala, dan opasitas' sebagai cakupan properti manual V1; jangan menampilkan rigging, bezier editor kompleks, motion graph atau efek profesional yang tidak disepakati.
- Field dan tombol harus realistis dan masuk akal untuk diimplementasikan, tetapi ini gambar referensi statis, bukan bukti fitur berfungsi.
